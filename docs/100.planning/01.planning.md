### 3.3 Anti-Pattern Self-Check (Step 3)

- ❌ Anemic Domain Modeling → rejected. Aggregates own invariants (weight sum,
  horizon range, seed immutability); behavior lives on `SimulationRun.run()`,
  not in service-layer `if`s.
- ❌ Gold-Plating Scalability → rejected. Single process, single user, single
  machine. No Kafka, no sharding, no multi-region. The README is explicit
  ("educational example").
- ❌ Resume-Driven Development → rejected. Stack is `uv`, `numpy`, `matplotlib`,
  `pydantic`, `structlog`, `click`. No Kubernetes, no Kafka, no Redis.
- ❌ Living Document Specification → rejected. All artifacts in this folder are
  frozen once this file is committed. Any change requires a new ADR superseding
  the old one.

## Quick-Reference Summary

Skim-readable condensation of this phase. For detail, follow the section anchors above.

### Mission

Freeze the bounded context, ubiquitous language, quantified NFRs, ADRs, contracts, and state machines that the Designing, Coding, and Testing phases will build against — so that nothing is left to interpretation downstream. Outcome of this phase: a single `RiskSimulation` context, 10 accepted ADRs, frozen OpenAPI / AsyncAPI / JSON-Schema contracts, C4 context + container diagrams, and an explicit anti-pattern rejection list. No third-party integrations, no production users — every decision is sized to a one-author, $0-budget educational repo.

### Key Decisions

- **ADR-001** single bounded context in v1 — keeps v1 shippable; folder seams (`market_data/`, `reporting/`) bound the cost of future extraction.
- **ADR-002 + ADR-010** import-linter + `mypy --strict` as CI gate — architectural boundaries are enforced, not convention.
- **ADR-003** JSONL event store on disk — no DB/broker; matches the $0 / single-process reality.
- **ADR-004** Pydantic v2 is source of truth, JSON Schema is generated — single point of truth, no drift.
- **ADR-005** CLI-only interface — no HTTP API in v1; the "user" is the author.
- **ADR-006** seeded numpy RNG, seed persisted per run — byte-for-byte reproducibility.
- **ADR-007** Docker compose as the single deployable — one command runs everything.
- **ADR-008** structlog JSON to stderr — observable without a log pipeline.
- **ADR-009** batched `PathSampled` (per 1k paths) — avoids log noise while preserving event semantics.
- **Rejected:** anemic domain, gold-plated scalability, resume-driven stack, living-document specs (see §3.3).
